# Bank Customer Churn & Retention Analytics

## Project Overview

Bank Customer Churn & Retention Analytics is an end-to-end data analytics and machine learning project developed to analyze customer churn patterns and identify customers who may require retention attention.

The project analyzes 1,000 bank customer records and uses Excel, MySQL, Python, Machine Learning, and Power BI to transform raw customer data into actionable business insights.

## Objectives

- Analyze overall customer churn
- Identify customer segments with higher churn rates
- Perform KPI analysis using Excel
- Perform relational analysis using MySQL
- Conduct exploratory data analysis using Python
- Identify statistically significant churn-related variables
- Develop a Logistic Regression churn prediction model
- Generate customer churn risk scores
- Build an interactive Power BI dashboard
- Provide data-driven customer retention recommendations

## Dataset

The dataset contains 1,000 bank customer records with the following attributes:

- CustomerId
- CreditScore
- Geography
- Gender
- Age
- Tenure
- Balance
- NumOfProducts
- HasCrCard
- IsActiveMember
- EstimatedSalary
- Exited
